# 后台原型合集 · 交互与业务联动补全版

2026-10-12

解压后打开 **开始浏览.html**，从目录进入工作台或具体页面。目录之外保留原有 40 个后台页面，assets 文件夹须与页面一起保留。

## 页面开发说明与交互演示指引（新增）

每页右下角新增两个悬浮入口，供开发、测试、产品核对字段与交互；41 页全部可用。

- **📋 字段说明**：按业务功能分 Tab，逐字段给出类型、长度/取值、是否必填、说明与校验。
- **🧪 交互演示指引**：按业务功能分 Tab，逐条给出交互场景、触发方式、预期效果，并说明状态流转与按钮可用性口径。

两个悬浮入口与抽屉均可拖动；抽屉支持 <kbd>Esc</kbd> 或点击遮罩关闭。页面自身弹出弹窗（原生 `dialog` 或整屏 `div` 遮罩）时，悬浮入口会自动隐藏避让，不会压住弹窗。

脚本为 `assets/meeting/meeting-devdoc.js`（外链，不依赖 Meeting 内核，也不改动任何既有共享脚本）。

字段长度口径来源：① 本原型真实 DOM 中带 `maxlength` 的输入直接采用其上限，控件类型与必填（`<span class="req">*</span>`）逐页提取；② 41 页「标签 → 控件」配对提取结果；③ 41 页结构摘要（标题/区段/字段/按钮/表头/弹窗）；④ `assets/meeting/*.js` 内既有校验与字典。凡本项目文档未定义、按原型尺度或行业惯例给出的参考值，均注明为「建议」。

### 权限与角色（41 页均有）

后台原型本身**不含前端角色分支**（无 `switchRole()` / `isHighRole()`，登录页为「管理员登录」，页头账号为单一演示管理员），因此「📋 字段说明」抽屉的末页签 **🔐 权限与角色** 不描述前端交互差异，而是**引用后端判权口径**：

- 口径来源《用户角色与权限说明-后端权限设计-20261012.md》v1.3（R1–R7 七角色、功能域 × 角色矩阵、高权限不可豁免项、数据隔离粒度），供后端建表与实现判权时逐条对照。
- 矩阵按 **功能域** 分组（工作台 / 账号 / 平台能力 / 数据 / 模型 / 课题 / 需求 / 运营内容 / 审批 / 科研空间 / 能力共享），列为「角色 / 可进入本页 / 本功能域操作级 / 说明」。
- 「数据 / 模型 / 科研空间 / 能力共享 / 审批」五个功能域另附「高权限的不可豁免项」小节。
- **管理设置**页在权限页签之外，另附 **🧩 角色字典 R1–R7** 页签，作为全平台角色字典入口。
- 状态标记：单元格以 `{{do}}` / `{{mid}}` / `{{opt}}` / `{{warn}}` / `{{no}}` / `{{info}}` / `{{req}}` 开头会渲染为彩色标签（可用 / 需申请 / 不适用 / 注意 / 禁用 / 品牌 / 必填）。
- ⚠️「高权限」是**能力标识而非角色**（仅全重实验室自有人员），按 L1 平台级 / L2 团队级两档理解。

### 新增页面时

在 `assets/meeting/meeting-devdoc.js` 顶部的 `DOCS` 中按**页面文件名**登记该页的 `field` / `guide` 内容，并在页面 `</body>` 前引入该脚本即可；未登记的页面显示通用说明。需要给某张表固定列宽时，在该 section 上加 `w: ['20%','16%','16%','48%']`（会自动启用固定表格布局，**列宽个数必须与表头列数一致**，否则末列为 0 宽会出现横向滚动）。

## 主要修复

- 统一课题工作台、成果验收审批、资源申请审批、运营管理与科研空间的数据读取；首次使用沿用包内已有的示例记录，已有本地记录不被覆盖。
- 工作台待办读取审批队列，携带具体申请编号跳转；审批后移入已办并回写结果。成果验收通过后进入对应模型或数据集列表；空间申请通过后进入科研空间管理。
- 科研空间列表按空间编号打开详情，启停、重启、配置保存与释放结果同步；其他空间不再套用第一个空间的文件、成员及成果。配置增加数值、资源上限与存储已用容量校验。
- 模型、数据集、案例、需求、通知公告按独立记录保存。新增、编辑、返回列表和再次打开详情衔接；保存并发布执行相应状态更新，清空列表后不重新填入初始记录。
- 指南年度、批次、正文、附件显示和研究方向随指南保存；新增与编辑不再共用上次内容，指南发布/撤回更新台账。科研人员按选择的研究方向标签匹配，并保留关键词和分页。
- 首页资源关联、简介及图文编辑按栏位保存，刷新后保留。
- 数据集新建可选择实际本地文件，保存后进入对应详情；资料保存回写列表，数据预览携带资源信息与预览类型。
- 修复目录入口、详情页回列表、记录定位、日期区间筛选、分页、空结果反馈以及部分富文本工具交互。
- 管理设置、时空数据管理、地图引擎仍沿用原有说明页；没有新增其业务功能或回收站。

## 使用与范围

- 本包是静态交互原型。审批、实例、构建、部署、接口调试和账号操作为本地演示，不连接生产后台。
- 页面通过浏览器本地存储交换记录。直接双击 HTML 可浏览；跨页联动建议将完整目录放在同一静态服务地址下访问。不同浏览器对 file:// 页面间存储共享的行为可能不同。
- 课题工作台默认使用当前记录；“演示数据”视图继续独立，只用于展示，不写入当前记录。
- 原型未附带真实模型镜像、数据源和遥感影像，原有材料入口展示文件信息；使用说明和页面原有的示例监测数值不代表真实平台数据。
