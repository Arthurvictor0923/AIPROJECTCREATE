解压后打开 **开始浏览.html**，或直接打开 **后台-工作台总览.html**。所有 HTML 页面均保留内嵌样式与脚本，可直接用桌面浏览器打开。

## 本次范围

原文件夹共 32 个原型。本包包含原有 32 页、6 个辅助页面和 1 个浏览目录，共 39 个 HTML 文件。

按最新要求，管理设置、时空数据管理、地图引擎三个文件保持原样，仅作为固定说明页；不新增回收站页面或入口。

## 使用说明

- 本包是交互原型，使用示例数据。审批、上传、实例启停、构建与部署不连接真实后台。
- 列表记录和部分表单通过当前浏览器本地存储保存；新页面和原页面间使用相对链接。更换浏览器或清除本地存储会恢复初始示例。
- 选择文件可以查看名称、大小或封面预览，不代表已上传到服务器。
- 原始数据、模型文件及真实遥感影像不在本包内；资源文件入口展示信息，数据查询页提供表格和影像示意。
- 三个固定说明页中的说明与原有交互未扩展，属于本次明确保留项。

## 验证

检查页面加载脚本、离线相对链接与内容溢出；验证课题新增/详情/状态流转、已办审批、案例新增回流与删除、消息已读、封面选择、富文本字号、构建部署弹窗、数据查询等主要交互。

## 2026-10-08 更新

- 替换模型管理与能力共享原型，保留原有导航、页面和相对链接。
- 模型管理支持平台部署及接口接入；能力共享包含接口管理、服务发布、免审批使用授权和自主上传的接口文档。
- 服务发布仅关联已登记接口；在线使用与试用独立开关。试用不按账户授权，免审批按账户与模型版本配置。
- 衔接三种原有模型详情编辑页面：按模型保存文字、富文本和上传预览，保存后返回列表；不同模型之间不共用编辑内容。
- 接通能力共享的消息、个人资料、账号安全和退出入口；从注册接口新建模型后，返回原窗口可选中新增模型。
- 建议将完整目录部署至同一个静态网站（如 GitHub Pages）后访问，以保证跨页、跨窗口存储一致。直接打开 file:// 时，各浏览器的本地存储行为可能不同。
- 接口调试、构建、部署和审批仍是原型演示，不代表真实接口连通或生产操作完成。
